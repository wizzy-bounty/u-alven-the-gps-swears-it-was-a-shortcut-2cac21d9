One line, under 200 characters: the GPS's own excuse for sending the driver down the wrong road. Smug, defensive, caught red-handed — and blaming the map.

## The entry

> I didn't send you into that cul-de-sac. The map did. I just repeated it louder because it sounded confident.

## How it works

`main.py` (Python standard library only, deterministic, no network) validates the line against the competition gate — UTF-8 text, 1–200 characters, a single line, not whitespace-only — and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), byte-exact with no trailing newline.

Run it locally:

```sh
python3 main.py
```
